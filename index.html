Structured 4-Module Curriculum

Click on any module to explore sub-topics, hands-on assignments, and learning outcomes.

  • Core Concepts: How the Web works, HTTP/HTTPS basics, Client-Server architecture.
  • Document Structure: Headings, Paragraphs, Lists, Anchors, and Media elements.
  • Semantic Markup: <header>, <nav>, <main>, <section>, <article>, <footer>.
  • Web Forms & Input Types: Labels, Text inputs, Radios, Checkboxes, and Validation attributes.
  • Project #1: Build a Semantic Single-Page Documentation Site.
  • CSS Fundamentals: Selectors, Specificity, Box Model (Margin, Border, Padding).
  • Modern Layouts: Master CSS Flexbox properties and CSS Grid area templates.
  • Responsive Web Design: Media queries, fluid typography, mobile-first design strategy.
  • Styling & Animations: Transitions, transforms, keyframe animations, and custom UI variables.
  • Project #2: Create a Fully Responsive E-Commerce Product Gallery.
  • JS Foundations: Variables (let, const), Primitive types, Type conversion.
  • Control Flow: Conditional statements (if-else, switch) and Loops (for, while, forEach).
  • Functions & ES6+: Arrow functions, scope, closures, destructuring, and template literals.
  • Data Structures: Working with Arrays, Array methods (map, filter, reduce), and Objects.
  • Project #3: Build an Interactive Task Manager & Grade Calculator.
  • DOM API: Selecting elements, modifying text, updating styles, and toggling CSS classes.
  • Event Handling: Click events, keyup listeners, submit events, and event delegation.
  • Form Processing: Regex email validation, phone input formatting, and error state handling.
  • Asynchronous Basics: Introduction to Web APIs, setTimeout, and dynamic DOM updates.
  • Project #4: Complete Landing Page with Accordion & Interactive Form Validation.
